# Roadmap

- **M0:** documentation, compatibility, manifest
- **M1:** service, overlay, bar widget, lifecycle
- **M2:** XDG state, schemas, migrations, locking, doctor, snapshot, credentials
- **M3:** native AppLibrary integration, search, layouts, folders, favourites, recent
- **M4:** manual web apps, desktop entries/icons, reconciliation, backup/rollback
- **M5:** Vercel, GitHub, cross-provider deduplication
- **M6:** Sync Center, settings, bar status, keyboard controls, dark design polish
- **M7:** security tests, compatibility matrix, clean install/update/remove, `v1.0.0`
